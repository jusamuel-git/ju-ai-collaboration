## 4. Jenkins 영향과 적용 순서

현재 PC-A Jenkins 설정 (오늘 오전 `config.xml` 확인): `globalNodeProperties` 비어 있음 → `JU_TOMCAT_HOME` **없음**. 이번 작업에서 Jenkins 설정은 바꾸지 않았다.

| 순서 | 할 일 | 담당 | 기존 빌드 영향 |
|---|---|---|---|
| 1 | Jenkins 관리 > System > Global properties > Environment variables에 `JU_TOMCAT_HOME = C:\MyData\MyTool\tomcat\apache-tomcat-10.1.52` 추가 | 사용자 (또는 승인 시 Claude가 내장 브라우저로) | **없음** — 현재 `main` Jenkinsfile은 이 변수를 쓰지 않는다 |
| 2 | ChatGPT diff 검토 → 사용자 승인 → `feature/env-0` commit, `main`에 반영·push | 사용자 | — |
| 3 | Jenkins `juprovider-ai`, `juproject-ai` `main` 빌드 SUCCESS 확인 | 사용자·Claude | juproject: `global.json` → Jenkins(LocalSystem)도 같은 SDK 10.0.402 사용, 영향 없음 예상 |
