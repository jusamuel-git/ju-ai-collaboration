## 4. 설계와 다르게 한 부분 (확인 요청)
1. **UK에 생성 컬럼 사용.** `PTL_CD`가 NULL이면 MariaDB UK가 중복을 막지 못함. 그래서 `PTL_CD_KEY = IFNULL(PTL_CD,'')` (PERSISTENT) 컬럼을 두고 UK를 여기에 걸었음.
2. **`CHANNEL_KEY`는 `utf8mb4_bin`.** C3 규칙("1"≠"01", 대소문자 구분)을 DB에서도 지키기 위해서임.
3. **설계 범위보다 조금 더 넣음.**
   - GTEC0002 RX 해석 규칙(INFO): 설계에는 0400만 있었지만 같은 검증값이라 넣었음.
   - `FRAME_RULE`에 `maxLen 512`: Desktop 내장 설정과 같게 맞춤.
4. **재실행해도 사용자 입력을 덮지 않음.** 정정은 새 컬럼이 NULL인 사용 중 행에만 함. 따라서 08 이후 화면에서 바꾼 값은 다시 실행해도 그대로임.
5. **응답 판정 regex 표기를 바꿈.** `\{`, `\d` 대신 `[{]`, `[0-9]`로 씀. SQL·JSON 이스케이프가 필요 없고 의미는 같음.
