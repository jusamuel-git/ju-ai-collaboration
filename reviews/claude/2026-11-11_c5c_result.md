- **원인**
  - Windows Smart App Control이 켜짐(강제) 상태다.
  - CodeIntegrity 이벤트 3033·3077이 남았다: 직접 빌드한 서명 없는 DLL을 `testhost.exe`·`C4SrvPlan.exe`가 로드하다 차단됨.

- **영향 범위**
  - Desktop 테스트·도구 실행이 막힌다.
  - Desktop 앱도 로컬 빌드 DLL이라 같은 차단이 예상됨 → **C5d 실장비 회귀에도 영향**.
  - 서버(Java)는 영향 없음.
- **결정 요청** (보안 설정이라 사용자 결정):

## 5. 확인 요청 (설계와 다르거나 새로 정한 부분)

1. **Action 계약을 v1로 유지하고 필드만 추가함.**
   - 기존 호출과 Vue 화면은 그대로 동작한다.
   - 대신 선택 텍스트(역할·표현식 등)를 비우는 기능은 v2(PR-L2)로 미룸.
2. **역할(PTL_ROLES)이 없는 프로토콜은 역할 연계 검사를 하지 않음.**
   - 대상: 과거 데이터 13개, 그룹 생성 때 자동으로 만들어지는 기본 프로토콜.
   - 기존 v1 호출 호환을 위해서다.
3. **기존 값을 그대로 다시 보내면 형식 검사를 하지 않음** (같은 순번 패킷의 같은 값 등).
   - 이 방식으로 GTEC0000 호환을 확보함.
4. **INIT_ROUTINE이 참조하는 프로토콜 보호 규칙을 추가함.**
   - 설계 §4 "사용 중 PTL_CD, RX_STREAM 불가" 규칙을 저장 이후에도 유지하려는 것이다.
   - 삭제는 409, RX_STREAM으로 변경은 400.
5. **C5c 서버는 migration 08이 적용된 DB가 필요함.**
   - 배포 순서: C5e(실제 DB 08) → C5c 서버.
6. **regex는 Java와 .NET 문법 차이가 있을 수 있음.**
   - 서버는 Java로 컴파일 가능한지만 확인한다.
   - GTEC 값은 양쪽에서 통과함.
