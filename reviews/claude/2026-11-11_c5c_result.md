## 4. 확인 요청 (설계 해석·추가 규칙)

1. **Action 계약**
   - v1을 유지하고 필드만 추가했다. 기존 호출과 Vue 화면은 그대로 동작한다.
   - 값을 비우는 기능은 v2(PR-L2)에서 다룬다.
2. **역할이 없는 프로토콜**
   - 대상: 과거 데이터 13개, 그룹을 만들 때 자동 생성되는 기본 프로토콜.
   - 이들은 역할 연계 검사를 하지 않는다 (v1 호환).
3. **같은 값을 다시 보낸 경우**
   - 기존 값을 그대로 다시 보내면 형식 검사를 생략한다.
   - GTEC0000 호환은 이 방식으로 확보했다.
4. **INIT_ROUTINE 참조 보호 (새로 추가한 규칙)**
   - 참조 중인 프로토콜 삭제 → 409, RX_STREAM으로 변경 → 400.
   - 설계 §4 규칙을 저장 이후에도 지키기 위한 것이다.
5. **배포 순서**
   - C5c 서버는 migration 08이 적용된 DB가 필요하다.
   - 순서: C5e(실제 DB 08) → C5c 배포.
6. **regex**
   - 서버는 Java 컴파일 가능 여부만 검사한다. Java와 .NET 문법 차이가 있을 수 있다.
   - GTEC 값은 양쪽 모두 통과한다.
