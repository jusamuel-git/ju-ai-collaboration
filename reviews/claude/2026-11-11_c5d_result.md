**CollectionPlanBuilder 규칙**

- 우선순위: **서버 → 내장(또는 지정) 설정 → 기본값**
- 출처 기록: 항목별 출처를 `Plan.Sources`에 남긴다.
  - 값: `server` / `builtin` / `profile` / `default` / `legacy-tagid`
- 누락·오류 기록: 서버 값이 없거나 잘못되어 다음 단계 값을 쓴 경우 `Warnings`에 남긴다.
- 그룹 설정
  - frameRule: JSON이 맞으면 서버 값.
  - cmdGapMs·initDelayMs: 서버 그룹 수집 설정이 있을 때만 서버 값.
    - "설정 있음" = frameRule 또는 initRoutine이 있거나, cmdGapMs > 0.
    - DB 기본값(0·500)만 있으면 미설정으로 본다.
  - initRoutine: 서버 목록이 있으면 서버 값.
- 프로토콜
  - 서버 roles가 있으면 "설정됨"으로 보고 PTL_TYPE·roles에 서버 값을 쓴다.
  - roles가 없으면(과거 데이터) 내장 보정을 쓰고, 그것도 없으면 PTL_TYPE을 쓴다.
  - action·expect·idempotent: 서버 → 내장 → 기본.
  - 송신: TX 패킷 → PTL_VAL → 내장.
  - 해석: RX JSON → 내장.
- 채널 매핑
  - data-map 행이 있으면 사용: scale·offset, PTL_CD 필터, 단위·범위는 태그에서 가져옴.
  - 행이 없으면 기존 `TAG_ID=CH<n>` 임시 변환을 그대로 쓴다.
