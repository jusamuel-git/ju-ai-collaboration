|---|---|

## 4. 테스트 항목
### 4.1 표현식·Frame·Parse
| ID | 내용 |
|---|---|
| E1 | seed의 모든 `PTL_VAL`·`PACKET_EXPR` → ToBytes → ToDisplay → ToBytes 왕복 동일 |
| E2 | 잘못된 표현식(닫는 `]` 없음, 모르는 이름, ASCII 밖 문자) → 명확한 오류 |
| F1 | DELIM: 한 프레임이 3조각으로 도착 / 여러 프레임이 한 번에 / 앞에 쓰레기 바이트 |
| F2 | STXETX + escape(DLE): 본문에 ETX가 escape되어 들어간 경우 |
| F3 | FIXED·LENFIELD(BE/LE, adjust, header 포함 여부), 최대 길이 초과 시 버퍼 초기화 |
| F4 | 체크섬 불일치 → 프레임 버림 + 사유 |
| F5 | 과거 GTEC 텍스트 규칙(`FRAME=CRLF;…`) → JSON 변환 동일 결과 |
| P1 | TEXT: GTEC 저속 `{1.23 4.56 7.89}` CHANNELS → 3값, 고속 SAMPLES 6값, 토큰 수 불일치 거부 |
| P2 | INFO: `{008,000,000,000}` → CH1 연결, CH2~4 미연결 |
| P3 | BINARY: I16 LE·F32 BE·scale·valueOffset |

### 4.2 응답 매칭 충돌 방지
| ID | 내용 |
|---|---|
| M1 | 요청 대기 중 연속 데이터(RX_STREAM) 프레임 도착 → 대기 명령에 연결되지 않고 스트림으로 분배, 이후 진짜 응답으로 완료 |
| M2 | 응답 형식이 같은 두 프로토콜(예: 장치확인·센서정보 모두 `{…}`) — 직렬 실행이라 진행 중 1개에만 연결됨, 순서 바뀜 없음 |
| M3 | 상관키(주소) 있는 병렬 모드: 응답 순서가 뒤바뀌어 도착해도 키로 정확히 연결 |
| M4 | 타임아웃 후 늦게 온 응답 → 다음 명령에 잘못 연결되지 않음(`LATE` 처리) |
| M5 | `Expect` 없는 레거시 TX_RX → "첫 프레임" 연결 + 경고 기록 |
| M6 | 같은 상관키로 두 명령 동시 등록 시 거부(`Rejected`) |

### 4.3 STOP 우선순위·취소
| ID | 내용 |
|---|---|
| S1 | 대기 큐에 INFO·POLL 여러 개 + STOP 등록 → STOP이 진행 중 명령 다음 첫 번째로 실행 |
| S2 | STOP 등록 시 같은 장치의 대기 중 START·PAUSE는 `Cancelled`, 다른 장치 명령은 유지 |
| S3 | START는 타임아웃 시 자동 재시도 안 함, INFO·설정 명령은 `RETRY_CNT`까지 재시도 |
| S4 | 진행 중 명령 취소 → 호출자는 즉시 `Cancelled`, Link는 응답/타임아웃까지 점유(다음 명령이 끼어들지 않음) |
| S5 | 연속 타임아웃 3회 → Link 의심 이벤트 1회 발생 |
| S6 | 폴링: 이전 회차 미완료면 이번 회차 건너뜀(큐에 쌓이지 않음) |
| S7 | Link 끊김 → 대기·진행 전부 `LinkDown` |

### 4.4 Data 식별자 안정성
| ID | 내용 |
|---|---|
| D1 | 같은 입력 → 항상 같은 `LogicalDataRef`(DAT_GR_CD, DAT_CD, DAT_IDX). 매핑 목록 순서를 바꿔도 결과 동일 |
| D2 | `ChannelKey`는 문자열 그대로 비교(`"1"` ≠ `"01"`, 대소문자 규칙 명시) — 위치 기반(TEXT)과 이름 기반(INFO/BINARY)이 섞여도 충돌 없음 |
| D3 | 한 채널 → 두 논리 Data(원값·환산값) 모두 생성, 서로 다른 키 |
| D4 | 매핑 없는 채널 → 값 버리지 않고 `UNMAPPED` 품질로 보고(조용히 사라지지 않음) |
| D5 | SAMPLES 모드: 같은 LogicalDataRef + SampleIndex 0..n 순서 보존 |
| D6 | `TAG_ID=CH<n>` 임시 변환이 매핑 테이블 형식과 **같은 LogicalDataRef**를 만든다 (나중에 테이블로 바꿔도 키 불변) |
| D7 | 동일 DEV_CD가 직접 장치·Gateway 하위로 바뀌어도 DeviceRef·LogicalDataRef 불변 (부모는 키에 포함 안 함) |
| D8 | 범위(DAT_MIN/MAX) 밖 값 → 값 유지 + `RANGE` 품질 |
